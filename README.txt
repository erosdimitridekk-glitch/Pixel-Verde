# Pixel Verde — Miniportfólio

Portfólio de página única criado para Eros / Pixel Verde.

## Estrutura

pixel-verde/
├── index.html
├── style.css
├── script.js
└── assets/
    ├── eros.png
    ├── hamburgueria.png
    ├── hotel.png
    └── sistema-hotel.png

## Como abrir

1. Extraia a pasta.
2. Abra o arquivo `index.html` no Chrome, Edge ou Firefox.
3. Não precisa instalar Node.js, banco de dados ou qualquer programa.

## Como trocar imagens

Entre em `assets/` e substitua:
- `eros.png` = imagem de apresentação/perfil
- `hamburgueria.png` = projeto da hamburgueria
- `hotel.png` = projeto do hotel
- `sistema-hotel.png` = imagem de referência visual da seção de automação

Mantenha os mesmos nomes para não precisar alterar o código.

## Como publicar gratuitamente

### GitHub Pages
1. Crie uma conta em github.com.
2. Crie um repositório, por exemplo `pixel-verde`.
3. Envie `index.html`, `style.css`, `script.js` e a pasta `assets`.
4. No GitHub, abra Settings > Pages.
5. Em Source, selecione a branch principal e a pasta `/root`.
6. Salve. O GitHub vai gerar um link público.

### Netlify
Também é possível arrastar a pasta do projeto para o Netlify e publicar como site estático.

## Observação

As imagens usadas são as três imagens fornecidas nesta conversa. O layout, fundos, ícones e elementos gráficos foram criados para compor a apresentação e não representam trabalhos adicionais.


## Nova seção — Automação de Sistemas

A seção "Automação de Sistemas" apresenta a Pixel Verde como uma área de atuação para criação de sistemas digitais personalizados, incluindo exemplos como gestão de quartos, cardápios e pedidos, sistemas financeiros e automação de processos.

A imagem `assets/sistema-hotel.png` é apresentada como exemplo visual de uma interface de gestão hoteleira. O portfólio deixa explícito que a imagem é uma referência visual e não afirma que esse sistema tenha sido desenvolvido pela Pixel Verde.
